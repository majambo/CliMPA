MIMP Climate Fact-Sheet: Consolidated Data & Reference Source List

This page consolidates all datasets, institutions, and literature references used to develop the Mafia Island Marine Park (MIMP) Climate Fact-Sheet, drawn from:

  • MIMP_Factsheet.pdf (published factsheet)
  • Critical_Climate_data_information.docx (Essential Climate Variable inventory and ecosystem threshold review)
  • data.xlsx (working data source and metrics tracker)

It is organised into four sections: (1) Essential Climate Variable data sources by theme, (2) Tanzania/WIO-specific and cross-cutting datasets, (3) literature and threshold references, and (4) global frameworks that informed indicator selection. Duplicate sources appearing across the original files have been merged into single rows.

Notes on Compilation

  • Sources are organised by GCOS Essential Climate Variable theme, consistent with the framing adopted in Section 2 of the “Identification of Critical Climate Data” working document.
  • Where the same institution or dataset appeared in more than one source file (for example NOAA Coral Reef Watch, ERA5, CHIRPS, or IBTrACS), the entries have been merged rather than repeated.
  • The current variable list is intentionally kept at a high level per the team’s working notes; derived indices such as DHW are listed separately from their parent variable (SST) rather than folded in.
  • Open item carried over from the working document: confirm whether the institutional data repository has a defined refresh cadence tied to the factsheet’s stated revision date, and who is responsible for triggering re-processing when new source data lands.
